# 📱 Samsung Mobile Sellout Analysis

## 📌 Project Overview

The **Samsung Mobile Sellout Analysis** project focuses on analyzing Samsung mobile sales data collected from **February to July**. The primary objective of this project is to transform raw sales data into meaningful business insights by applying data cleaning, SQL-based analysis, and interactive data visualization techniques.

The project follows a complete data analytics workflow, beginning with cleaning and preparing the dataset in Microsoft Excel to ensure data accuracy and consistency. Once the data was prepared, SQL was used to perform exploratory analysis, calculate key business metrics, identify top-performing products, rank sales performance, and answer various business-related questions.

Based on the SQL analysis, important **Key Performance Indicators (KPIs)** such as **Total Sales, Total Quantity Sold, Average Selling Price, Product Rankings, and Performance Metrics** were identified. These insights were then visualized using **Microsoft Power BI**, where an interactive dashboard was designed to provide a comprehensive view of sales trends, product performance, and overall business performance.

The dashboard enables users to monitor sales performance through dynamic visualizations, KPI cards, and charts, allowing stakeholders to quickly identify trends, compare product performance, and make data-driven business decisions.

This project demonstrates practical skills in **Data Cleaning, SQL Query Writing, Business Analysis, KPI Development, Data Visualization, and Dashboard Design**, making it a complete end-to-end Business Intelligence project.
